## Deviations from the plan

- `vitest.workspace.ts` (plan layout) is not used; Vitest 5 expects
  `test.projects` in `vitest.config.ts` (ADR-0022).
- pnpm 12.4.2 does not fail an install on the root project's own `engines`
  field, contrary to its docs; the Node pin is enforced by `.node-version`
  and CI (ADR-0018, research note section 3).
- pnpm 12 reads settings from `pnpm-workspace.yaml`, so there is no `.npmrc`.
- ADRs 0018..0023 go beyond the plan's literal "ADRs for the decisions in this
  document", per AD-016.
- Only three packages exist; every other planned package directory is
  deliberately absent rather than stubbed.

## Environment note

The bootstrapping machine ran Node 23 with a Corepack pnpm shim that could
not download pnpm 12. Node 24.21.0 and pnpm 12.4.2 were installed
user-locally (`~/.n`). Nothing in the repository depends on that path.
