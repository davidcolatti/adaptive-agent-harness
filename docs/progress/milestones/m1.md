## Goal

Run one neutral `eve` agent locally through the harness API, without
compilation. Deliverable: the first real reusable harness call. That call is
`pnpm example:run:mock`, which drives the vendor-triage domain through
`createHarness()` and `EveAgentRuntime` against a real `eve dev` server with a
scripted model, and returns a schema-valid `completed` result.

## Deviations from the plan

- `createHarness({ agentRuntime, storage })`: `storage` is omitted until M2
  defines the `Storage` contract; no placeholder type was invented.
- `AgentRuntime` receives a `Job`, whose output schema is only a string
  reference until a registry resolves it, so `EveAgentRuntime` takes the
  domains' output schemas at construction (`domains` option). M2/M5 should
  route this through the capability registry.
- eve 0.63.0 has no in-process run API; the adapter is an `eve/client` HTTP
  client and never spawns a server. `startEveDevServer` (a `./testing` subpath)
  spawns one for tests and the example script. eve also has no `eve check`
  command; `eve info` is the diagnostic.
- Per-run tool permission is enforced by observing the event stream and
  cancelling, which is detection rather than prevention. Recorded as an M1
  limitation in ADR-0028 with eve's auth-plus-approval composition as the
  upgrade path.
- eve replaces authored models with an internal mock when `NODE_ENV=test` or
  `EVE_MOCK_AUTHORED_MODELS=1` (undocumented); the dev-server helper strips both
  so the fixture's scripted `mockModel` is actually used under Vitest.
- eve's client type for `outputSchema` is `StandardJSONSchemaV1 | JsonObject`,
  narrower than its docs claim; the adapter lowers the domain schema itself
  (zod 4.6.5 publishes the converter).
- Trace `sequence` numbers are assigned independently by the harness and by the
  adapter within one run, so they can collide until M2-T4's writer owns
  sequencing. `TraceEvent` is a five-field placeholder for M2-T3.
- A core -> testing dev dependency (cyclic workspace graph plus a turbo
  override) was introduced and then reverted during M1-T4; core's own tests use
  local doubles.
